# Agent entry point

For cross-repository MS-DIAL family development, read the master prompt in the
private repository `systemsomicslab/msdial-family-dev-context`,
cloned beside this one as `..\context\prompts\00-msdial-family-development-master-prompt.md`,
before inspecting or editing code. It contains the local repository, SDK, demo-data, scientific,
validation, privacy, and Git/PR context shared across MS-DIAL Console,
MS-DIAL Interactive, Repository Catalog, vendor raw metadata, and public
reanalysis.

For public repository reanalysis orchestration, also read `CLAUDE.md` and the
task-specific skill/prompt. Verify the current checkout and runtime state rather
than treating dated branch or version notes as authoritative.
